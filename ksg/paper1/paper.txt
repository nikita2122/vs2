Research for Solving Multi-Target Scheduling of School Bag Factory Production by Using
Resource-Coupled Heterogeneous Graph Attention
Computer Science Short Paper
Companion to the system-design thesis
October 2026
Abstract
A school-bag line is a flexible job shop in which an operation starts only when a machine, a skilled operator,
and often a shared die or thread lot are free together. The same decision must serve several targets: makespan,
tardiness, energy, and workload balance. This paper presents resource-coupled heterogeneous graph attention
(RCH-GAT). Each feasible action is a bundle, and each bundle is scored by one-hop attention over an operation
node, a machine node, an operator node, and a shop node that reads token contention. A preference vector opens
the nodes, so one score can be asked to protect due dates or energy. Twenty coefficients are identified by the
cross-entropy method on a school-bag simulator. On twenty nominal order books the score, without maintenance,
finishes in1234minutes and211 kWh, against about1521minutes and303 kWhfor first-in-first-out. Colour
features are specified and, under ample lots, nearly silent. The numbers are estimates of this implementation.
1 Introduction
Classical dispatching chooses the next job by a single key. First-in-first-out uses release time. Shortest processing
time uses duration. Earliest due date uses the promise date. Apparent tardiness cost mixes slack and duration with
a look-ahead [6]. Each rule is rational for the target written into its key, and each is silent about the targets that
are not. A school-bag shift cares about all of them at once. Cutting, embroidery, lockstitch, bartack, hardware,
inspection, and packing can run on more than one resource, but the resource is not a machine alone. An operator
without the skill, or a khaki thread lot already held by another body, makes the machine idle in the schedule even
while the machine record says it is free.
Graph methods already represent flexible job shops. The disjunctive graph separates conjunctive precedence from
machine choices [2, 3]. Heterogeneous graph networks learn embeddings of operations and machines and pick an
operation–machine pair by reinforcement learning [13, 12, 11]. Those models are the right lineage. Textile shops have
been searched with ant-colony methods [15], and energy together with labour has been treated as a many-objective
flexible job shop [7]. They still stop one resource short of this factory. The pair(operation,machine)does not name
the operator, and it does not name the die or the colour lot. A policy trained on that pair can recommend a bundle
the shop cannot start.
The contribution of this paper is a score that refuses that recommendation before it is ranked. The action is the

4 Identification and estimate
The twenty coefficients were identified by the cross-entropy method: population36, elite8,28generations, starting
from a log-prior that already blends processing time, slack, and health. The training books are seeds11,23,37, and
41. The best scalar relative to first-in-first-out fell from about0.450to0.366. Changingωin (4) without repeating
the search does not trace a reliable Pareto front. A new preference is a new identification.
Table 1 reports means over twenty paired books, seeds1000–1019, sixteen orders, nominal wear and nominal token
capacities. RCH is the graph score with maintenance off. The other rows are rules that share the same mask and
the same plant. Tardiness standard deviations are several hundred minutes, so a gap of a few tens of minutes in
tardiness is not a ranking. Makespan and energy gaps are large beside their spreads.

5 What the fit is doing
The cross-entropy search did not spread weight evenly. Table 2 keeps the costs whose weights exceed0.9, which are
the ones that moveψon a typical candidate. Load imbalance is an order of magnitude above processing time. A
machine that is already busy is expensive even when its cycle is short. Skill sits next, so a slow substitute operator
is not a free way to grab an idle machine. Failure and setup outrank the raw minutes of the cycle. Colour, at0.133,
does not appear in the table because it lost the identification.
Dispatch is then a short loop. At the current time, list every operation whose predecessor is done and whose order
is released. For each such operation, list eligible free machines, skilled free operators, and a free token if the step
needs one. Score each surviving bundle by (5) and commit the minimum. Advance the clock to the next instant at
which a machine and an operator are both free, release tokens of finished work, and repeat. No priority list is frozen
at the start of the shift. A rush order enters the list at its release minute and is scored with whatever health the
machines have by then.

6 Conclusion
RCH-GATmakestheschool-bagdecisionamaskedbundleandscoresthatbundlebypreference-conditionedattention
on operation, machine, operator, and shop nodes. On the simulator the identified one-hop score shortens and cools
the day relative to first-in-first-out, shortest processing time, earliest due date, and apparent tardiness cost, and it
